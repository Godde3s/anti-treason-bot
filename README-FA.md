# 🛡️ ربات ضد خیانت کانال — نسخه ۲.۶ (اعلان قفل در کانال + هم‌گام با آخرین تلگرام + دوزبانه + نام/منشن + ویرایش دسترسی)

رباتی که نگهبان کانالتونه: **هر ادیت یا ارسال غیرمجاز رو در چند صد میلی‌ثانیه شناسایی و حذف می‌کنه — حتی اگه پیام چند روز پیش باشه و همین حالا ادیت شده باشه.** همه‌چیز از طریق یک پنل فارسی و زیبا در پیوی ربات مدیریت می‌شه؛ توسط مالک و هر کسی که مالک بهش دسترسی ادمین بده.

## 🚀 راه ۱ — دیپلوی خودکار با اسکریپت (سریع‌ترین روش)

اگر دستیار هوشمندتون (یا خودتان در ترمینال) توکن Cloudflare داشته باشه، دیپلوی با یک دستور تمام می‌شه:

```bash
CLOUDFLARE_API_TOKEN=xxxx  bash scripts/deploy.sh
```

اسکریپت به‌ترتیب این کارها رو خودکار انجام می‌ده: اعتبارسنجی توکن → پیدا کردن اکانت → ساخت فضای KV (`anti-treason-kv`) → ساخت `WEBHOOK_SECRET` تصادفی → آپلود ورکر با REST API (**حتی wrangler هم لازم نیست**؛ فقط `curl` و `node`) → فعال‌سازی آدرس `workers.dev` → چاپ آدرس نهایی و لینک `?setup=`.

> 💡 اگه توکن به چند اکانت دسترسی داره: `CLOUDFLARE_ACCOUNT_ID=yyyy CLOUDFLARE_API_TOKEN=xxxx bash scripts/deploy.sh`

**بعد از دیپلوی فقط ۲ کار مونده (عمداً به خودتون سپرده شده):**
1. داشبورد → **Workers & Pages** → `anti-treason-bot` → **Settings** → **Variables and Secrets** → **Add** — هر دو از نوع **Secret** (تا در دیپلوی‌های بعدی پاک نشن):
   - `BOT_TOKEN` = توکن از @BotFather
   - `OWNER_ID` = شناسه عددی خودتون (اختیاری ولی توصیه‌شده)
2. آدرس زیر رو در مرورگر باز کنید تا وب‌هوک وصل شه (اسکریپت همینو بهتون می‌ده):
   ```
   https://<آدرس-ورکر>/?setup=<WEBHOOK_SECRET>
   ```

### 🔑 توکن Cloudflare چه دسترسی‌هایی لازم داره؟

**ساده‌ترین راه:** موقع ساخت توکن، قالب آماده **«Edit Cloudflare Workers»** رو انتخاب کنید — دقیقاً همین‌ها رو داره و کافیه:

| نوع | دسترسی | سطح | چرا؟ |
|---|---|---|---|
| Account | **Workers Scripts** | Edit | آپلود و بروزرسانی کد ورکر |
| Account | **Workers KV Storage** | Edit | ساخت فضای KV و ذخیره تنظیمات |
| Account | Account Settings | Read | پیدا کردن خودکار Account ID |
| User | User Details / Memberships | Read | بررسی توکن و لیست اکانت‌ها |

- ❌ دسترسی **Zone** لازم نیست — ربات روی `workers.dev` اجرا می‌شه و دامنه‌ای به اکانت وصل نیست.
- 📍 مسیر ساخت: [dash.cloudflare.com/profile/api-tokens](https://dash.cloudflare.com/profile/api-tokens) → **Create Token** → قالب **Edit Cloudflare Workers** → **Continue to summary** → **Create Token** → کپی.
- 🔒 بعد از دیپلوی می‌تونید همون توکن رو حذف/Roll کنید؛ دیگه لازمش ندارید (برای دیپلوی دوباره یکی جدید بسازید).

## 🖱 راه ۲ — دستی از داشبورد (بدون ترمینال)

### مرحله ۱ — ساخت ربات در تلگرام (BotFather)

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدید و دستور `/newbot` رو بزنید.
2. یک **نام نمایشی** بدید (مثلاً: `نگهبان کانال من`).
3. یک **یوزرنیم** بدید که حتماً به `bot` تمام شه (مثلاً: `MyGuardChannel_bot`).
4. BotFather یک **توکن** به شکل `123456789:AAH...` می‌ده. **این توکن رو کپی و نزد خودتون نگه دارید** (مثل رمز عبوره!).

### مرحله ۲ — ساخت Worker در Cloudflare

1. وارد [dash.cloudflare.com](https://dash.cloudflare.com) بشید.
2. از منوی چپ: **Workers & Pages** → دکمه **Create** → **Create Worker**.
3. یک اسم بدید (مثلاً `anti-treason-bot`) → **Deploy** رو بزنید (همون کد پیش‌فرض فعلاً مهم نیست).
4. بعد از دیپلوی، دکمه **Edit code** رو بزنید.
5. کل کد پیش‌فرض سمت چپ رو پاک کنید و **تمام محتوای فایل `worker.js`** رو Paste کنید.
6. بالا-راست دکمه **Deploy** رو بزنید. ✅

> 🌐 آدرس ورکر شما چیزی شبیه `https://anti-treason-bot.نام-اکانت.workers.dev` است — همین آدرس در مرحله ۵ لازم می‌شه.

### مرحله ۳ — ساخت دیتابیس KV و اتصال به ربات

تنظیمات ربات (قفل‌ها و کانال‌ها) باید جایی ذخیره بشه؛ Cloudflare KV این کار رو رایگان انجام می‌ده:

1. در همان داشبورد: **Storage & Databases** → **KV** → **Create a namespace**.
2. اسم بذارید: `anti-treason-kv` → **Add**.
3. حالا برگردید به ورکر: **Workers & Pages** → روی `anti-treason-bot` کلیک کنید → تب **Settings** → بخش **Bindings** → **Add** → **KV namespace**.
4. در قسمت **Variable name** دقیقاً بنویسید: `KV` (حروف بزرگ) و از لیست پایین، فضای `anti-treason-kv` رو انتخاب کنید → **Deploy** (برای اعمال تغییرات دوباره دیپلوی لازمه).

### مرحله ۴ — متغیرهای محیطی (خیلی مهم!)

| نوع | نام | مقدار | توضیح |
|---|---|---|---|
| Secret | `BOT_TOKEN` | توکن BotFather از مرحله ۱ | الزامی |
| Secret | `WEBHOOK_SECRET` | یک رشته تصادفی لاتین/عدد (مثلاً `Xk29fTq7mZb1`) | الزامی — امنیت وب‌هوک |
| Secret | `OWNER_ID` | شناسه عددی خودتان | اختیاری ولی **توصیه می‌شه** |

> 🆔 **شناسه عددی خودتان را از کجا بگیرید؟** اول ربات را نصب کنید، در پیوی‌اش `/start` بزنید و دکمه «🆔 شناسه من» را بزنید — یا از [@userinfobot](https://t.me/userinfobot) بپرسید.
>
> ⚠️ اگر `OWNER_ID` را تنظیم نکنید، **اولین کسی که `/start` بزند مالک ربات می‌شود** — پس بهتر است بعد از گرفتن شناسه‌تان آن را ست کنید و دوباره Deploy بزنید.

بعد از افزودن متغیرها، **Deploy** بزنید.

### مرحله ۵ — وصل‌کردن تلگرام به ورکر (ست‌کردن Webhook)

**🎯 راه آسان (جدید!):** فقط این آدرس را در مرورگر باز کنید — ربات خودش همه‌چیز را تنظیم می‌کند:

```
https://<آدرس-ورکر>/?setup=<WEBHOOK_SECRET>
```

اگر همه‌چیز درست باشد، پیام `✅ وب‌هوک وصل شد` را می‌بینید.

**🔧 راه دستی (معادل همان):** این آدرس را با توکن و آدرس ورکر خودتان باز کنید:

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https%3A%2F%2F<WORKER-URL>%2Fwebhook&secret_token=<WEBHOOK_SECRET>&max_connections=40&drop_pending_updates=true&allowed_updates=%5B%22message%22%2C%22callback_query%22%2C%22channel_post%22%2C%22edited_channel_post%22%2C%22my_chat_member%22%5D
```

پاسخ درست: `{"ok":true,"result":true,"description":"Webhook was set"}`

> 🔍 برای چک وضعیت هر زمان: `https://api.telegram.org/bot<TOKEN>/getWebhookInfo`

### مرحله ۶ — اضافه‌کردن ربات به کانال

1. در کانال خود: **مدیریت کانال** → **مدیران** → **افزودن مدیر** → ربات را انتخاب کنید.
2. از بین دسترسی‌ها، حداقل این را فعال کنید:
   - ✅ **حذف پیام‌ها (Delete messages)** ← **الزامی! بدون این، ربات نمی‌تواند قفل‌ها را اجرا کند**
   - بقیه دسترسی‌ها اختیاری‌اند.
3. به محض ادمین‌شدن، ربات کانال را خودکار ثبت می‌کند و در پیوی شما پیام «✅ ربات در کانال ادمین شد» می‌فرستد.
   (اگر ربات را قبل از `/start` به کانال اضافه کرده باشید، با اولین `/start` لیست کانال‌های ثبت‌شده به شما نشان داده می‌شود.)
4. در پیوی ربات `/start` بزنید → **📋 کانال‌های من** → کانال را انتخاب کنید و قفل‌ها را تنظیم کنید!

### منوی کانال
```

🆔 -100xxxxxxxxxx
🔒 قفل‌های فعال: 3 از 20
⏰ قفل زمان‌دار: ✅ فعال از 04:00 تا 20:00
🚨 قفل آنی: خاموش
🔴 وضعیت قرمز: روشن
⏱ مدت بن خودکار (در وضعیت قرمز): همیشگی
🗑 حذفیات ثبت‌شده: 12
[🚨 قفل آنی (بستن کامل)]
[🟡/🔴 وضعیت زرد/قرمز]
[⏱ مدت بن خودکار (قرمز): همیشگی]
[🔒 قفل‌ها] [⏰ قفل زمان‌دار]
[👑 ادمین‌های کانال]
[💾 بکاپ تنظیمات] [📥 بازگردانی]
[📊 آمار] [🩺 سلامت]
[🔄 بروزرسانی] [🔙 کانال‌ها]
```

### 🚨 قفل آنی — بستن کامل تا وقتی خودت باز کنی
دکمه اول منوی هر کانال:
- لمسش کنی → **از همون لحظه هر پیام یا ادیتی، از هر نوعی (متن، عکس، ویدیو، استیکر، فوروارد و…)** فوراً حذف می‌شه.
- **تا وقتی دوباره لمس کنی و «🔓 باز کن» رو نزدی** قفل می‌مونه — حتی اگه روزها بگذره؛ چیزی خودبه‌خود باز نمی‌شه.
- وضعیتش بالای منوی کانال مشخصه: `🚨 قفل آنی: فعال 🔒 (از تاریخ/ساعت)` و دکمه‌اش تبدیل به «🔓 قفل آنی روشن — باز کن» می‌شه. تو لیست «کانال‌های من» هم کانال قفل‌شده با 🚨 علامت می‌خوره.
- این قفل **مستقله**: به قفل‌های تکی و قفل زمان‌دار دست نمی‌زنه؛ بعد از باز شدن همه‌چیز مثل قبله.
- گزارش هر حذف با دلیل «قفل آنی (دستی)» به پیوی مالک میاد.
- مثال کاربرد: موقع سفر / وقتی حس می‌کنی ادمین‌ها دارن سوءاستفاده می‌کنن / emergency کامل — یک لمس و کانال کاملاً بسته می‌شه.

### قفل‌ها — یعنی چی؟
روی منوی «🔒 قفل‌ها» هر آیتم یک دکمه است: 🔴 = فعال، 🟢 = آزاد. با لمس، وضعیت عوض می‌شه و **از همان لحظه** اجرا می‌شه:

- **ادیت متن** → هر کسی متنِ هر پستی را ادیت کند، کل پست فوراً حذف می‌شود (حتی پست‌های چند روز/ماه پیش).
- **ادیت مدیا** → هر تغییری در کپشن عکس/ویدیو/… حذف می‌شود.
- **لینک در ادیت** → فقط ادیت‌هایی که داخلشان لینک باشد حذف می‌شوند (ضد تبلیغ پنهان در پست‌های قدیمی!).
- **ارسال‌ها** → هر نوع پست را جداگانه می‌توانید ببندید.
- **فوروارد** → هر پست فورواردی حذف می‌شود.
- **لینک** → هر پستی که لینک داشته باشد (چه entity چه متن خام مثل `t.me/...`) حذف می‌شود.
- **پست ناشناس** → هر پست/ادیتِ «بدون امضای ادمین» حذف می‌شود (توضیح کامل در بخش v1.9 پایین).
- **قفل کامل** → هیچی ارسال یا ادیت نمی‌شود؛ کانال کاملاً بسته است.
- **⛔️ قفل همه / ✅ آزاد کردن همه** → تغییر یکجای ۲۰ قفل (روی «قفل آنی» اثری نداره).

### قفل زمان‌دار (همان سناریوی شبانه شما)
از منوی «⏰ قفل زمان‌دار»:
1. **🔔 فعال‌سازی** را بزنید.
2. **🕐 شروع** → مثلاً بنویسید `4:00` (ارقام فارسی `۴:۰۰` هم قبول است).
3. **🕗 پایان** → مثلاً `20:00`.
4. **🎛 حالت** → با هر لمس عوض می‌شود: 🚫 ارسال و ادیت → 📤 فقط ارسال → ✏️ فقط ادیت.

در بازه فعال، هر چیزی که طبق حالت ارسال یا ادیت شود **فوراً حذف** می‌شود و گزارشش به پیوی مالک می‌رود. بیرون بازه همه‌چیز آزاد است.

> 💡 نکته‌ها: همه ساعت‌ها به وقت **تهران (Iran/Tehran — UTC+3:30)** است • اگر شروع و پایان یکی باشد قفل ۲۴ساعته است • بازه‌های شبانه مثل `22:00` تا `6:00` درست کار می‌کنند • ایران دیگر ساعت تابستانی ندارد و ربات هم حساب نکرده — یعنی همیشه دقیق است.

### آمار، لاگ و سلامت
- **📊 آمار:** مجموع حذفیات، تفکیک ادیت/ارسال، ۵ دلیل پرتکرار، تاریخ شمسی آخرین تخلف + دکمهٔ «📜 آخرین تخلف‌ها» (۱۵ مورد اخیر با متخلف و نتیجهٔ حذف) + ریست.
- **📝 لاگ پیوی:** گزارش هر حذف برای مالک + ادمین‌ها + ناظرها ارسال می‌شود و شامل منشن و آیدی متخلف است.
- **🩺 سلامت:** نشان می‌دهد ربات ادمین است یا نه و کدام دسترسی‌ها را دارد. اگر «حذف پیام» ❌ بود، قفل‌ها اجرا نمی‌شوند!

### ادمین‌ها و دسترسی کانالی (v2.0)
مالک از «👥 ادمین‌های ربات» با شناسهٔ عددی ادمین اضافه می‌کند — بلافاصله **ویرایشگر «📡 کانال‌ها»** باز می‌شه تا دقیقاً تعیین کنی اون ادمین به کدوم کانال‌ها دسترسی داشته باشه:

- ✅/❌ روی نام هر کانال = دادن/گرفتن دسترسی — **ادمین فقط همین کانال‌ها را می‌بینه و مدیریت می‌کنه**؛ تنظیمات ربات و بقیهٔ کانال‌ها برایش قابل دسترسی نیست.
- «🌐 همهٔ کانال‌ها» = دامنهٔ عمومی (با افزودن کانال جدید، خودکار شامل می‌شه) — «🎯 محدود به انتخاب‌ها» برمی‌گرداند.
- **ادمینِ بدون کانال هیچی نمی‌بینه** (امن پیش‌فرض) — تا وقتی مالک کانالی براش تعیین نکنه.
- **گزارش تخلف هر کانال فقط برای مالک + ادمین‌ها/ناظرهای همان کانال می‌ره.**
- ادمین هیچ‌وقت نمی‌تونه: ادمین اضافه/حذف کنه، کانال فعال/رد کنه، یا کانال دیگه‌ای رو ببینه.
- ادمین‌های تعریف‌شدهٔ قبل از آپدیت، خودکار به «کانال‌های ثبت‌شدهٔ فعلی» مهاجرت می‌شن — بعداً می‌تونی محدودشون کنی.

> ادمین‌های کانالِ تلگرامی (👑 ادمین‌سازی در کانال) جدا از این بحث‌اند: اون‌ها ادمینِ خودِ کانال تلگرام‌اند، نه ادمینِ پنل ربات.

### 👑 ادمین‌های کانال (ادمین‌سازی سریع از داخل ربات — v1.8 + گروهی v2.1 + ویرایش v2.2)
از منوی کانال، «👑 ادمین‌های کانال»: (در همهٔ فهرست‌ها نام و منشن هر نفر کنار شناسه‌اش هست — v2.2)
- **➕ افزودن ادمین جدید:** شناسهٔ عددی فرد را بفرست (یا @یوزرنیم) — یا **لیست شناسه‌ها (v2.1)**: با کاما یا خط جدید جدا کن (مثال: `111, 222, 333`؛ حداکثر ۵۰) تا **همه با هم** ادمین بشن — کیبورد با ⚡️ **پریست‌های یک‌ضربه‌ای** باز می‌شه:
  - «⚡️ ادمین معمولی»: ارسال پست + حذف پیام (پیشنهاد ما — بدون ادیت!)
  - «👑 ادمین کامل»: همهٔ دسترسی‌ها به‌جز ناشناس
  - «📣 ناشناس (پست با نام کانال)»: ناشناس + ارسال + حذف
  - یا دستی: ۹ دکمهٔ تک‌تک + «✅ همه / ⛔ هیچ‌کدام» → «تأیید و ارتقا» (برای گروه هم کار می‌کنه).
- **📋 گزارش گروهی (v2.1):** بعد از ارتقای گروهی، نفر‌به‌نفر اعلام می‌شه: هر ✅ ادمین شده و هر ❌ با دلیل فارسی (مثلاً «کاربر شناخته نشد»، «مالک کانال است»، «از قبل ادمین است»). شناسه‌های تکراری/نامعتبرِ لیست هم قبل از شروع نادیده گرفته می‌شن و تعدادشون اعلام می‌شه.
- **➕ ادمین بعدی:** بعد از هر ارتقا (پریست یا دستی) این دکمه هست تا چند ادمین را پشت‌سرهم بدون برگشتن به منو اضافه کنی.
  - اگر فرد از قبل ادمین باشه (فلو تکی)، دسترسی‌های فعلی‌اش لود می‌شه تا اصلاحشون کنی.
  - اگر ربات دسترسی «**Add New Admins**» نداشته باشه، پیام دقیق می‌ده که از تنظیمات ادمینی تلگرام فعالش کنی.
- **⬇️ عزل ادمین:** فهرست ادمین‌های فعلی (مالک کانال با 👑 مشخصه و قابل عزل نیست) — با تأیید دومرحله‌ای، همهٔ دسترسی‌های ادمینی گرفته می‌شه (بن نمی‌شه). در پیام تأیید هم نام/منشن فرد نمایش داده می‌شه.
- **⚙️ ویرایش دسترسی (v2.2):** کنار دکمهٔ عزل هر ادمین، دکمهٔ «⚙️ ویرایش دسترسی» هست — ۹ دسترسی فعلی فرد لود می‌شه؛ تغییر بده و «✅ تأیید و ارتقا» بزن تا همین دسترسی‌ها آپدیت شن (عزلی در کار نیست). مالک کانال قابل ویرایش نیست.

### 🟡🔴 نردبان وضعیت + ↩️ بازگردانی (v1.8)
دکمهٔ وضعیت در منوی کانال **سه‌حالته** است و با هر زدن می‌چرخه: `خاموش → 🟡 زرد → 🔴 قرمز → خاموش`:
- **خاموش:** هیچ عزل خودکاری نیست؛ ادیت‌ها فقط طبق قفل‌ها (مثل «قفل ادیت مدیا») پاک می‌شن.
- **🟡 زرد (فقط عزل):** هر کسی پستی را که مدیا داره (عکس/فیلم/گیف/…) ادیت کنه ⇒ ۱) پیام فوراً پاک ۲) ادمین‌بودن متخلف **عزل** ۳) گزارش زرد فوری. بن نمی‌شه.
- **🔴 قرمز (عزل+بن):** همان زرد + متخلف از کانال **بن** می‌شه و گزارش قرمز با دکمهٔ «♻️ لغو بن» میاد.
- در زرد/قرمز، ادیتِ پستِ فقط-متنی هم پاک می‌شه (بدون عزل/بن).
- **↩️ بازگردانی:** قبل از عزل، دسترسی‌های فعلی متخلف snapshot می‌شه (۲۴ ساعت در KV)؛ در گزارش دکمهٔ «بازگردانی دسترسی‌های قبلی» همه رو دقیقاً برمی‌گردونه — اگر تطبیق امضا اشتباه بود، با یک کلیک جبران می‌شه.
- **محافظت‌ها:** خودِ ربات و **مالک کانال** (creator) هرگز عزل/بن نمی‌شن — گزارش توضیح می‌ده.
- **شناسایی متخلف:** اگر تلگرام فرستنده رو بده که مستقیمه؛ در کانال‌ها معمولاً نمی‌ده — ربات امضای پست رو با ادمین‌های کانال تطبیق می‌ده و فقط در صورت تطبیق قطعی (یک نفر) اجرا می‌کنه؛ وگرنه گزارش می‌ده تا دستی از «👑 ادمین‌های کانال» عزلش کنی.
- ربات باید دسترسی «Ban Users» (برای بن) و «Add New Admins» (برای عزل) داشته باشه — در گزارش هر کدوم نشد، دقیق توضیح داده می‌شه.

### 👁 ناظرها (فقط مشاهده)
مالک از «👁 ناظرها» می‌تواند افرادی را اضافه کند که **فقط تخلف‌های کانال‌های تعیین‌شده‌شان را ببینند**: گزارش پیوی، «📜 آخرین تخلف‌ها» و آمار.
ناظر نمی‌تواند هیچ قفلی بزند یا تنظیمی عوض کند — و از v2.0 فقط کانال‌هایی را می‌بیند که مالک برایش انتخاب کرده (ویرایشگر «📡 کانال‌ها» کنار هر ناظر).

### 📡 چندکاناله (v2.0)
- ربات را در هر تعداد کانال ادمین کن — هر کانال جداگانه ثبت می‌شه و با «✅ فعال‌سازی» فعال می‌شه؛ **همه همزمان فعال می‌مونن**.
- «📋 کانال‌های من» برای مالک همهٔ کانال‌ها را نشون می‌ده؛ برای ادمین/ناظر فقط کانال‌های خودش.
- هر کانال قفل‌ها، وضعیت زرد/قرمز، زمان‌دار، بکاپ و آمار مستقل خودش رو داره.
- اگه کانالی از تلگرام حذف/خارج بشه، خودکار از لیست پاک می‌شه (به بقیه کانال‌ها دست نمی‌زنه).

### 🔒⏱💾 قابلیت‌های v1.9

#### 🔒 قفل پست ناشناس — هیچ‌کس بدون هویت خودش پست ندهد
از «🔒 قفل‌ها» دکمهٔ «پست ناشناس» را روشن کن:
- هر پستی که **بدون امضا** (ناشناس = از طرف خودِ کانال) ارسال یا ادیت شود، **فوراً حذف می‌شود** و گزارش با دلیل «قفل پست ناشناس» می‌آید.
- پستِ امضادار (با هویت ادمین) کاملاً آزاد است.
- **نحوهٔ امضادارشدن پست‌ها:** در تنظیمات دسترسی هر ادمین کانال، گزینهٔ **«Sign messages»** را روشن کن (در اپ رسمی تلگرام موقع ویرایش دسترسی هر مدیر)؛ برای پست‌های خودت هم «امضای کانال» را در تنظیمات کانال فعال کن. از آن به بعد امضای هر ادمین زیر پستش می‌آید و پست‌هایش حذف نمی‌شود.
- با قفل «ارسال متن» می‌توانی همزمان پستِ فقط-متنی را هم کلاً ببندی.

#### ⏱ مدت بن خودکار (فقط برای وضعیت قرمز)
در منوی کانال، دکمهٔ «⏱ مدت بن خودکار» با هر لمس می‌چرخد: **همیشگی → ۱ ساعت → ۲۴ ساعت → ۷ روز**.
- در وضعیت 🔴 قرمز، متخلفِ ادیت‌کننده علاوه بر عزل، به همین مدت بن می‌شود (`until_date`) و بعد از مدت، تلگرام خودش بازش می‌کند.
- دکمهٔ «♻️ لغو بن (بخشیدن)» در گزارش قرمز همیشه هست (برای بن موقت هم کار می‌کند).

#### 💾 بکاپ و 📥 بازگردانی تنظیمات
- «💾 بکاپ تنظیمات» → یک پیام با متن JSON تنظیمات (قفل‌ها، وضعیت زرد/قرمز، مدت بن، قفل آنی، زمان‌دار، لاگ و…) می‌دهد — آن را کپی و جایی نگه دار.
- «📥 بازگردانی» → همان متن را بفرست (با یا بدون کدبلاک ` ``` `) تا همه‌چیز دقیقاً برگردد؛ ورودی نامعتبر پیام خطا می‌دهد و چی را خراب نمی‌کند.
- کاربردها: انتقال تنظیمات به کانال دیگر، بازیابی سریع بعد از تغییر اشتباهی، نگهداری نسخهٔ پشتیبان.

#### 📅 آمار امروز + 📣 گزارش آزمایشی
- در «📊 آمار تخلفات» خط جدید «📅 امروز (تهران)» تعداد تخلف‌های امروز را جدا نشان می‌دهد (با نیمه‌شب تهران خودکار صفر می‌شود).
- در «👥 ادمین‌های ربات» دکمهٔ «📣 گزارش آزمایشی» به **مالک + همهٔ ادمین‌ها + ناظرها** پیام تستی می‌فرستد — اگر کسی پیام را دید، یعنی گزارش‌ها به او می‌رسد. (گزارش‌های تخلف از قبل برای همین جمع ارسال می‌شدند؛ این دکمه برای اطمینان است.)

## 🆓 محدودیت‌های پلن رایگان — آخره؟ نه!

نسخه ۱.۵ مخصوصاً برای «لیمیت نخوردن» بهینه شده است:

| منبع | سهمیه رایگان | مصرف این ربات (v1.5) |
|---|---|---|
| درخواست Worker | ۱۰۰,۰۰۰ در روز | هر پست/ادیت = ۱ درخواست؛ برای تقریباً همه کانال‌ها کافی است |
| خواندن KV | ۱۰۰,۰۰۰ در روز | هر پیام ۱ خواندن (با کش ۱۰ ثانیه‌ای بهینه شده تا قفل‌ها خیلی سریع اعمال شوند) |
| نوشتن KV | ۱,۰۰۰ در روز | ⚡️ آمار و «آخرین تخلف‌ها» در **یک** کلید ادغام شدند (یک نوشتن به‌جای دوتا) + حداقل **۲۵ ثانیه** فاصله بین فلاش‌ها ⇒ حتی در موج تخلف هم سهمیه پر نمی‌شود |
| پیام‌های تلگرام | لیمیت ارسال تلگرام | ⚡️ در موج تخلف، گزارش‌های پیوی تا ۵ ثانیه در **یک خلاصه** ادغام می‌شوند (اولی فوری می‌رود) ⇒ نه لیمیت می‌خوری نه گزارشی گم می‌شود |
| درخواست حذف | — | ⚡️ برای پیام‌های قطعاً قدیمی‌تر از ۴۸ ساعت، درخواست حذفِ محکوم‌به‌شکست اصلاً ارسال نمی‌شود |

تنها حالتِ که هنوز می‌شود آمار ناقص ثبت شود، بیش از ~۱هزار تخلف در روز است — و حتی آن هم با فاصلهٔ حداقلی فلاش خیلی سخت اتفاق می‌افتد؛ خودِ حذفکردن همیشه کار می‌کند چون به نوشتن نیاز ندارد.

### ⚙️ تنظیم‌های اختیاری بهینه‌سازی (Variables)
| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `FLUSH_MS` | ۱۵۰۰۰ | فاصلهٔ ذخیرهٔ آمار (میلی‌ثانیه) |
| `MIN_FLUSH_GAP_MS` | ۲۵۰۰۰ | حداقل فاصلهٔ بین دو فلاش آمار — هرچه بیشتر، نوشتنِ KV کمتر |
| `REPORT_WINDOW_MS` | ۵۰۰۰ | پنجرهٔ ادغام گزارش‌های پیوی در موج تخلف (۰ = غیرفعال) |

## 🤖 حذف خودکار پیام‌های قدیمی با اکانت (یوزربات)

ربات روی Cloudflare نمی‌تواند پیام‌های قدیمی‌تر از **۴۸ ساعت** را حذف کند (محدودیت خود تلگرام — هیچ رباتی نمی‌تواند). اما **اکانت انسانیِ ادمین این محدودیت را ندارد!**

از نسخهٔ ۱.۶: هر پیام قدیمی که ربات نتوانست حذف کند، در یک **صف** در KV کلادفلر ثبت می‌شود. اسکریپت کوچک `userbot.py` (کنار همین پکیج) که با **اکانت خودت** اجرا می‌شود، هر ۱۰ ثانیه صف را چک می‌کند، پیام‌ها را با اکانت تو حذف می‌کند و نتیجه را به پیوی مالک گزارش می‌دهد + در «📜 آخرین تخلف‌ها» با علامت «🗑 حذف شد (با اکانت) 🤖» ثبت می‌شود.

**چرا جدا از Cloudflare؟** پروتکل اکانت‌های تلگرام (MTProto) روی Workers پلن رایگان عملی نیست (سقف CPU و نشست دائم). این اسکریپت خودش صف را می‌کشد ⇒ **هیچ پورت باز، دامنه یا سرور عمومی لازم نیست** — هر دستگاهی که اینترنت داشته باشد کافی است:
- 💻 یک VPS ارزان یا رایگان (مثلاً Oracle Cloud Always Free)
- 🖥️ کامپیوتر/لپ‌تاپ خودت (هر وقت روشن باشد فعال است؛ صف ۲۴ ساعت نگه می‌دارد)
- 📱 حتی گوشی اندروید قدیمی با اپ Termux

### نصب گام‌به‌گام

**۱) API ID بگیرید:** سایت `my.telegram.org` → Login با شماره‌ات → «API development tools» → یک اپ بساز → `api_id` و `api_hash` را بردار.

**۲) پایتون + Telethon:**
```bash
python3 -m pip install telethon
```

**۳) فایل `userbot.env` کنار `userbot.py` بساز:**
```ini
WORKER_URL=https://anti-treason-bot.<YOUR-SUBDOMAIN>.workers.dev
SECRET=<همان WEBHOOK_SECRET ورکر>
API_ID=<api_id مرحله ۱>
API_HASH=<api_hash مرحله ۱>
POLL_SECS=10
```

**۴) اجرا:**
```bash
python3 userbot.py
```
اولین بار: شماره‌ات را با فرمت `+98…` بده، کدی که تلگرام می‌فرستد را وارد کن (و رمز دوم اگر داری). نشست در `anti-treason-ub.session` ذخیره می‌شود و دیگر سؤال نمی‌کند. تمام — از این به بعد هر پیامِ قدیمیِ تخلفی خودکار با اکانتت حذف می‌شود.

> ⚠️ **هشدار صادقانه:** تلگرام با اکانت‌های خودکار سخت‌گیرتر است. این اسکریپت فقط درخواستِ حذفِ تخلف (حجم بسیار کم) اجرا می‌کند، ولی ریسک به‌صورت صفر قابل تضمین نیست — یک اکانت کم‌اهمیت‌تر را ادمین کانال کن اگر نگرانی. مسئولیت استفاده با خودت است.

> 💡 اکانت باید **ادمین کانال** بماند و یک‌بار در لیست دیالوگ‌هایش دیده شده باشد (کافی است اکانت عضو کانال باشد — هست).

| آدرس `?setup=` می‌گوید «کلید اشتباه است» | مقدار بعد از `?setup=` باید دقیقاً همان `WEBHOOK_SECRET` باشد |

## 🔐 نکات امنیتی

- توکن ربات، `WEBHOOK_SECRET` و `OWNER_ID` را از نوع **Secret** ذخیره کنید (نه Text) — ضمناً در دیپلوی‌های بعدی هم پاک نمی‌شوند.
- `WEBHOOK_SECRET` باعث می‌شود فقط تلگرام بتواند به ورکر شما درخواست بفرستد؛ اندپوینت `?setup=` هم با همین رمز محافظت می‌شود.
- اگر `OWNER_ID` را ست نکنید، اولین `/start` مالک می‌شود — هرچه زودتر ستش کنید.
- توکن ربات را در هیچ‌جا (گروه، کانال، گیت‌هاب عمومی) منتشر نکنید؛ اگر لو رفت، در BotFather با `/revoke` توکن جدید بگیرید.
- توکن Cloudflare را فقط به دستیار/اسکریپت مورد اعتماد بدهید و بعد از دیپلوی حذف یا Roll کنید.

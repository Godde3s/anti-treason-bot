What it does›

Everything about the channel, in one panel. See and change every channel's locks, mode and stats from the bot's DM. You never open the channel.

The panel handles the rest. Scoped admins, batch add, quick access, per-channel bot access, onboarding, one-tap presets, time-window locks, in-channel announcements, broadcast, delete recent, rich messages and update dedup.

Two versions, one bot. The same bot in two runtimes. The live version runs on tgcloud; the Cloudflare Worker is the backup. Run only one per token.

Deploy to Cloudflare
How to deploy on Cloudflare›
  1. Press Deploy to Cloudflare above.
  2. Set BOT_TOKEN and OWNER_ID as Secrets.
  3. Deploy, then open the setup link the worker shows to finish.
npx tgcloud push
How to deploy on tgcloud›
  1. Clone the repo and open the tgcloud folder.
  2. Create a Serverless app and copy its CLI token.
  3. Run npx tgcloud push with the token set.
  4. The webhook syncs itself — the bot is live. This is the live version, rev 12.

Both are free. One minute to deploy. Free, open source, no card.

Questions

The answers, plainly.

Deploy the bot

What permissions does the bot need?

Only Delete messages is required. Add New Admins is needed for in-bot promotion and Ban Users for red mode.

How do I add a new admin?

The owner sends the numeric ID, or a list of up to 50 IDs at once. Then ticks the channels that person may manage.

Why can't some old messages be deleted?

That is Telegram's own limit: no bot can delete messages older than 48 hours. The Cloudflare userbot closes the gap.

How does the anonymous-post lock work?

Any post without an admin signature is deleted at once. Admins sign with Sign messages.

How do the two versions differ?

They are the same bot with the same core features. tgcloud is live and adds force-join and exactly-once announcements; Cloudflare is the backup and has the userbot and previous-bot fallback. Run only one per token.

Is the Cloudflare free plan enough?

Yes. The bot uses about 0.3% of the 100k daily requests, and batched flushing keeps KV writes under the cap.

What about security and privacy?

Tokens live only as secrets, never in code or the repo. Only the owner can change settings. The code is open source (MIT).

Deploy the bot in a minute.

Two ways: the Cloudflare button or the tgcloud command. Both are free.

Press the button, set BOT_TOKEN and OWNER_ID as Secrets, then open ?setup=.
